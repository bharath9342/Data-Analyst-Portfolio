# Bharath — Data Analytics Portfolio

A responsive, dark navy and blue portfolio website built with plain HTML and CSS.

## Preview locally
1. Open `index.html` in your web browser.
2. To edit, open `index.html` in VS Code or a text editor.

## Publish free with GitHub Pages
1. Open https://github.com/bharath9342/Data-Analyst-Portfolio
2. Before changing anything, check the existing files and keep your current project files.
3. Add `index.html` to the repository's top level (the same level as README.md).
4. Commit the change.
5. Open repository **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/(root)`, then click **Save**.
8. Wait a few minutes and use the **Visit site** link shown in Pages settings.
